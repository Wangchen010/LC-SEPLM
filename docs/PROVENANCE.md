# Release provenance

This directory was assembled on 2026-11-19 from the internal manuscript release candidate, with documentation revised for an external audience. It contains selected code, results, and figure source data for the LC-SEPLM manuscript. It excludes internal manuscript drafts, local environments, raw third-party datasets, pretrained weights, and model checkpoints.

The repository is not a complete reproduction archive. See [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md) for included and missing materials.
